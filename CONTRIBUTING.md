# Contributing to FrameLab

FrameLab is a static site — no build step, no dependencies. Vanilla HTML/CSS/JS + Canvas.

## Run it locally

```bash
npx serve .
# or
python3 -m http.server
```

Open it in your browser and make something.

## File an issue

Check the Issues tab first — yours might already be there. Say what happened, what you expected, and the steps to see it again. A screenshot helps more than a paragraph.

## Send a PR

Fork, branch, change, PR. Keep it small and focused — one fix or one feature per PR. Match the code around it (plain JS, clear names, comments only where the why isn't obvious). Test in your browser before you send it: the wizard, a 2D generation, and a 3D preview if you touched them.

## Code style

Plain, readable, no cleverness — if a teammate can't follow a line, rewrite the line.
